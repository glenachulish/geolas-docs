# geolas-docs

Public-facing documentation for the Geòlas app: the privacy and support pages required by App Store Connect.

This repo exists to satisfy App Store requirements for policy URLs while keeping the app's own project separate. One copy, not two — edit here, commit here.

Published via GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

If Geòlas's network use or data handling ever changes, update privacy.md in the same commit as the change that requires it — the claim that matters here is the specific one about what leaves the device, and it needs to stay true.
